- **Impact:** Cluster exposed to internet, potential unauthorized access

- **Impact:** Potential data exfiltration

### 1. Docker Containers Running as Root
- **Affected Files:**
  - `/home/user/A2A/Dockerfile`
  - `/home/user/A2A/ggen/ontology/Dockerfile`
  - `/home/user/A2A/marketplace/Dockerfile`
  - `/home/user/A2A/craftplan/*/Dockerfile`
  - `/home/user/A2A/erlang/a2a_erl/Dockerfile`

- **Fix:** Add to each Dockerfile:
  ```dockerfile
  RUN adduser -D -u 1000 appuser
  USER appuser
  ```

### 2. Inefficient Package Installation
- **Issue:** Missing `--no-install-recommends` flag in apt-get
- **Impact:** Larger image sizes, more attack surface
- **Fix:**
  ```dockerfile
  RUN apt-get update && apt-get install -y --no-install-recommends \
      package1 package2 \
      && rm -rf /var/lib/apt/lists/*
  ```
